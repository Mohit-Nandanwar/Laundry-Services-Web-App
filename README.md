# Laundry-Services-Web-App
The Laundry Services Web App is a modern, responsive web application designed to make laundry booking simple, fast, and convenient for customers. It combines a clean interface with practical features to streamline the entire process of exploring services, adding items to a cart, and confirming bookings.


✨ Features
Landing Page (Front Screen)

Hero section with a large washing machine image.

Headline and description highlighting premium laundry care.

Clear “Book Service Today” button that navigates to the booking page.

Booking Page

Service List: Dry Cleaning, Wash & Fold, Ironing, Stain Removal, etc.

Dynamic Cart: Add/remove services with real-time updates.

Total Calculation: Automatic total price display.

Booking Form: Collects customer details (name, email, phone).

Email Confirmation: Sends order details via EmailJS.

Redirect Flow: After booking, users are redirected to the subscription page.

Subscription Page

Newsletter form with name and email fields.

Encourages users to stay connected for offers and updates.

Additional Sections

Service Overview: Highlights achievements (15+ services, 240+ happy customers, 2+ years experience).

Quality Description: Premium services, quick support, timely delivery, affordable prices.

Footer: Essential links and social media icons.
